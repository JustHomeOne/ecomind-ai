# EcoMind AI

Панель экологического мониторинга одного ЖК по документу «Хакатон: идея 2.0».

**Сайт:** https://justhomeone.github.io/ecomind-ai/

## Запуск

Node.js 20+; установка зависимостей не нужна.

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Проверки: `npm run check`.

## Возможности

- Адаптивная панель с 12 демонстрационными контейнерами, фильтрами и поиском.
- Интерактивная схема квартала, переключение 2D/3D, масштабирование и географическая карта MapLibre / OpenFreeMap.
- Ручные наблюдения; локальное сохранение; экспорт CSV.
- Анализ фото через совместимый сервер, настроенный в интерфейсе. Ключ Gemini никогда не передаётся в клиентский код.
- Отбор остановок по календарю, текущему заполнению или линейному сценарию; ближайший сосед + 2-opt.
- Матрица сравнения 3 × 2, отдельно показывающая вклад порядка остановок.
- Текущий европейский/американский AQI, PM2.5, PM10 и открытый модельный прогноз из Open-Meteo / CAMS.

## Автоматическая публикация

Каждый push в `main` запускает `.github/workflows/deploy-pages.yml`: проверка синтаксиса, тесты алгоритма и публикация `dist/` в GitHub Pages. Секреты для Pages не требуются. В Settings → Pages должен быть выбран источник **GitHub Actions**.

## Данные и ограничения

Исходные площадки, адреса, заполненность и темпы роста — демонстрационные. Они не являются результатами полевого пилота. Новые наблюдения сохраняются в localStorage текущего браузера без синхронизации устройств. Фото в localStorage не сохраняется.

Карта-схема художественная, без точного воспроизведения зданий ЖК. Географическая карта использует реальные тайлы OSM; демонстрационные точки не подтверждают существование контейнеров по этим координатам.

Расстояния геодезические, с настраиваемой поправкой (по умолчанию 1.3). Маршрут не учитывает уличный граф, одностороннее движение, ограничения грузовика и обязательные вывозы. Время: сценарные 20 км/ч плюс 3 минуты на остановку. Это расчётная симуляция, а не навигация или доказанная экономия. Сценарий роста линейный; собственная модель прогноза ещё не обучена. Матрица сравнивает один момент, без многодневного перерасчёта притока.

Данные воздуха модельные, не показания датчика во дворе. Прогноз получен от CAMS, а не модели EcoMind. Отсутствующие данные остаются отсутствующими. Европейский и американский AQI — разные шкалы. Нет доказанного влияния вывоза на воздух района.

## Сервер анализа фото

В настройках можно указать URL собственного HTTPS FastAPI-сервера с:

- `GET /api/health` → `{ "gemini_configured": true }`;
- `POST /analyze` (multipart: `image`, `latitude`, `longitude`, заголовок `Accept: application/json`);
- ответ: `container_detected`, `contents_visible`, `fill_percentage` (0–100 или null), `fill_category`, `overflow_detected`, `confidence` (`low`, `medium`, `high`), `explanation`, `limitations`.

Сервер должен разрешать CORS только для нужного origin. API-ключ храните в серверной переменной окружения `GEMINI_API_KEY`, никогда в Git. Без сервера и ключа доступны ручные наблюдения и остальные модули.
